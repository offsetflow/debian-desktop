# 旧版 `.xinitrc` 部署迁移设计

## 目标

解决旧版仓库生成的 `~/.xinitrc` 转发入口阻塞 `scripts/deploy.sh`，
导致 `.zshrc` 未部署且默认 Shell 未切换到 Zsh 的问题。

## 行为

- `~/.xinitrc` 不存在时，保持现有行为，创建指向仓库 `x11/xinitrc` 的软链接。
- `~/.xinitrc` 已是正确软链接时，保持现有幂等行为。
- `~/.xinitrc` 是内容完全匹配旧版入口的普通文件时，将其替换为正确软链接。
- 其他普通文件或错误软链接仍视为冲突，绝不覆盖。
- 迁移只适用于 `.xinitrc`，不放宽其他配置文件的冲突保护。

旧版入口的精确内容为：

```sh
#!/bin/sh

exec "$HOME/workspace/personal/debian-desktop/x11/xinitrc" "$@"
```

## 实现

为 `scripts/deploy.sh` 的链接部署函数增加可选的“受信任旧文件”参数。
仅当目标是普通文件且与受信任模板逐字节相同时，删除该目标并立即创建软链接。
`.xinitrc` 调用提供仓库管理的旧版模板；其余调用不提供。

旧版模板保存在仓库测试夹具中，避免用模糊字符串或路径包含判断误判用户配置。

## 验证

- 先新增测试，证明当前部署脚本会拒绝旧版入口。
- 实现后验证旧版入口可迁移为正确软链接。
- 验证任意用户自定义 `.xinitrc` 仍保留且部署失败。
- 运行部署测试、Shell 语法检查、完整测试集和 `git diff --check`。
- 在当前环境运行部署、设置默认 Shell和健康检查。
